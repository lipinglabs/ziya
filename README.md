# 字芽 · 幼儿识字与语音意识启蒙

给 4 岁孩子的识字游戏。不是把一年级课本做成题，而是按年龄窗口拆成三层：

```
现在（4 岁）      识字认读 + 语音意识
5 岁后            拼音符号系统
5 岁半            拼音 ↔ 识字打通，进入指读
```

**为什么 4 岁不教拼音**：拼音是抽象符号系统，前置能力是「音素意识」（押韵、首音、音节切分、声调），多数儿童 5 岁后才成熟。4 岁硬上，典型结果是 b/d、p/q 反复分不清，形成「学习=难受」的初始印象。

## 铁律（继承自 lilearn-english）

1. **音频按主题组打包成独立 `.js`**，严禁内联进 `index.html`。
2. **凭据不进仓库**：豆包 TTS 的 Key 只从环境变量或 `~/.workbuddy/secrets/doubao.env` 读取。
3. **禁止 `git push`**：本机推送被网络拦截，必须用 `tools/publish.js` 走 GitHub Data API。
4. 本项目为中文识字内容，属「沉浸感铁律（纯英文）」的**明确例外**。
5. **每次发版必须改 `sw.js` 的 `VERSION`**，否则老用户会一直跑缓存里的旧版。

## 设计要点

- **间隔重复取代通关制**：每个字有独立掌握度，每次打开看到的是「今天该复习什么」，不是「上次玩到第几关」。
- **题目由数据推导**：改一个字表读音，全部题目自动跟着变，不存在「背题库」。
- **拼读不另做音频**：M3 拼读机直接复用 310 字的读音，做到「拼出来的音就是一个真的字」，拼音与识字当场打通。
- **多音字不进单字音频**：`数`、`只` 孤立朗读会读错，出题自动改走词音频。
- **插图有互斥表**：一碗饭/一碗粥/一碗汤、几个圆器皿、两片叶子/一丛草，这些图不能同时出现在一道题里，否则考的是「猜」不是「认」。
- **新字优先安排有图的词**：具体名词先于抽象字，4 岁更容易建立「字—物」对应。
- **错题不惩罚**：答错只重听、再试一次；两次未对自动揭示答案，永不卡住。
- **单次 12 分钟**：到点温和收尾。

## 数据

正式进度存在 `localStorage` 的 `ziya.v1`；试用模式写在**完全独立的** `ziya.sandbox.v1`，两者互不影响，当前模式记在 `ziya.mode`。换设备走家长面板「导出备份 / 导入备份」。

自己测试、给孩子演示，**先开试用模式**（家长面板 → 试用模式），否则测试数据会变成孩子的真实学习记录。

## 题型阶段

题型不是一开始就全上，按**已学字数**推进（不按年龄，学得快就早点上难的）：

| 阶段 | 触发 | 包含题型 |
|---|---|---|
| 1 看图为主 | 已学 < 24 字 | 看图选字、看字选图（无图的字回落到听音） |
| 2 加听音 | 24–79 字 | 再加 听音选字、听词选字 |
| 3 全部 | ≥ 80 字 | 再加 字→词、字→读音（拼音开关打开时） |

理由：不识字的孩子做「听音选字」只能靠猜，先让他在「形↔义」之间建立联结，有了一批熟字之后再进「音→字」。

## 新手提示

孩子还不识字，四选一等于让他猜。所以**每个字前 10 次出现**，进入题目 **5 秒**后给一个柔和的圈标出正确项；**第 11 次出现起自动撤掉**。计数存在 `data.appear`（与掌握度 `chars` 分开，互不污染）。

例外：声调题的选项本身就是音高曲线，看图就能选，圈答案会废掉耳朵训练，所以不做提示。

## 语音时序

全站单声道：`A.play()` 会先掐掉正在播的声音，避免叠音；`A.playThen()` 保证「读字 → 鼓励 → 进下一题」严格串行，不会出现鼓励语压住下一题题干。
